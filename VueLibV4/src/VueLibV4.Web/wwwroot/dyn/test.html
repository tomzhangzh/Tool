Dyn. V4 Demo

短语法动作系统 · 仅一套语法 · 组合动作 $before / $onSuccess / $onFail / $after

data-dyn-{event}-{action} = "{...}"
AppA.count{{model.count}} msg{{model.msg}} price{{model.price}} num{{model.num}} total{{model.total}}

1 calc · 安全表达式运算

不使用 eval，仅支持简单赋值运算，直接读写共享 model

data-dyn-click-calc='{"expr":"count += 1"}'

2 setvar · toast 提示

设置变量值、弹出轻提示

data-dyn-click-setvar='{"path":"msg","value":"来自按钮设置"}'

3 组合动作 · confirm 前置确认

$before 先确认，用户点"确定"才执行 postback；失败走 $onFail，无论成败最后走 $after

data-dyn-click-postback='{"$before":[{"action":"confirm","options":{"message":"确定提交？"}}],"url":"/api/mock/save","message":"保存成功"}'
取消确认将中止请求

4 chain · 动作链

按顺序执行多个动作，前一步结果可作为 $result 传递

data-dyn-click-chain='{"steps":[{"action":"calc","options":{"expr":"count += 1"}},{"action":"toast","options":{"message":"chain 完成"}}]}'

5 open · 弹窗 + onopen/onclose + reloadSelf

打开弹窗加载远程片段；关闭后自动刷新触发按钮所在容器

data-dyn-click-open='{"url":"/mock/dialog.html","title":"编辑","reloadSelf":true,"onopen":[...]}'
/mock/dialog.html 需后端提供，否则显示加载失败

6 switch · 条件分支

按 model 值匹配分支执行对应动作，支持 default 兜底

data-dyn-click-switch='{"expr":"model.count","cases":[...],"default":{...}}'

7 triggerevent · 事件总线

通过 bus 发布事件，DynLib.ready 里可订阅

data-dyn-click-triggerevent='{"name":"my-bus-event","payload":{"val":999}}'

8 init · 初始化动作

页面就绪 / ajax 片段加载完成后自动执行，只执行一次

data-dyn-init-toast='{"message":"页面初始化完成"}'
msg 已由 init 自动改写
