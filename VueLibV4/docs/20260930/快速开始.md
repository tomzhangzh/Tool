# VueLibV4 快速开始

> 文档版本：2026-09-30 · 适用代码库：VueLibV4（.NET 8 分支）
> 从零到跑通，预计 5 分钟。

---

## 1. 平台是什么

VueLibV4 是一个 **ASP.NET Core 8 + Vue 3（UMD 无打包）的企业级低代码平台**：

- **免模型动态 CRUD**：知道表名即可分页查询 / 新增 / 更新 / 删除，后端不需要为每张表建实体。
- **可视化页面设计器**：拖拽组件 → 配置属性 → 保存为 DynWebPage → 运行时动态渲染。
- **三屏积木体系**：筛选区（Filter）/ 列表区（List）/ 详情区（Detail）配置独立、模板拼装，页面生成向导一键产出整套 CRUD 页面。
- **组件双定义源**：Razor View（`.cshtml`，代码优先）+ 数据库 `ComponentMeta`（回退）。
- **双桌面壳**：Windows 风格工作台桌面 + macOS 拟物风格桌面。

## 3. 获取代码并运行

```powershell
# 在仓库根目录（VueLibV4.sln 所在目录）
dotnet run --project src/VueLibV4.Web --urls http://localhost:5010
```

> 端口说明：项目固定使用 **5010**（`appsettings.json` 的 `Urls` 配置）。
> 若直接 `dotnet run` 不带 `--urls`，会读取 `Properties/launchSettings.json` 的开发端口 5116。
> 本文档所有地址均以 5010 为准。

首次启动时 `Seeder` 自动完成（全部幂等，可重复启动）：

1. 在 `src/VueLibV4.Web/bin/Debug/net8.0/App_Data/` 下创建两个 SQLite 库：
   - `Platform.db` —— 平台库（11 张表）
   - `Business.db` —— 业务库（Student / Course / BusinessDict + 演示数据）
2. 依次执行 `Data/platform.sql` → `component-meta.sql` → `seed-extra.sql` → `update-property-config.sql`。
3. 旧库自动增量迁移（补表、补列、改名、补种子），不删数据。

看到日志 `[Init] 平台库初始化完成` 与 `[Init] 业务库初始化完成` 即成功。

### 解决方案结构（3 个项目）

```
VueLibV4.sln
└─ src/
   ├─ VueLibV4.Web/        Web 站点（Areas 控制器/视图、Seeder、前端 wwwroot）
   ├─ VueLibV4.Platform/   平台层（11 张表的模型 + Service + 页面生成器）
   └─ VueLibV4.Services/   基础层（SqlSugar 工厂、免模型 CRUD、Emoji、扩展方法、DI）
```

## 5. 一分钟体验：设计一个表单页面

1. 打开 **设计器** `/Platform/Page/Designer`。
2. 左侧「组件库」→「容器」→ 拖 `DynElContainer` 到画布；再往里面拖两个 `DynElInput`。
3. 点击输入框 → 右侧属性面板填 **绑定字段（modelname）**，如 `name`、`age`。
4. 顶部「保存」→ 输入页面 Code 与名称，保存为 DynWebPage。
5. 访问 `/Platform/Page/WebPageRender?code=你的Code` 查看运行时效果。

**嵌套容器怎么拖：** 往容器里再拖一个容器即可形成嵌套。拖拽时：

- 所有可放置容器显示**淡蓝虚线候选框**；
- 鼠标悬停且能接收 → **绿色高亮**；不能接收（类型不允许 / 拖进自身）→ **红色禁止**并拦截；
- 空容器平时显示浅蓝占位框「＋ 拖放组件到此处」。

> 注意：`按钮 / 输入框 / 图片` 这类组件是表单交互元素，设计器内通过点击选中，拖动排序请按住组件外层区域（或在左侧「结构树」中调整层级）。

## 6. 三分钟体验：免模型 CRUD

平台已自带 `Business.db` 与 Student 演示数据。

### 方式 A：页面生成向导（推荐）

1. 打开 `/Platform/Page/PageGen`；
2. 选项目（缺省业务库）→ 选表 `Student` → 勾选字段 → 生成；
3. 系统自动产出 **3 条 PageSetting（Filter/List/Detail）+ 1 条 DynWebPage**；
4. 在页面实例管理中打开，即得到完整的查询 / 新增 / 编辑 / 删除页面。

### 方式 B：直接调 API

```bash
# 分页查询
curl "http://localhost:5010/api/business/dyndata/page?table=Student&page=1&size=10"

# 条件过滤（POST search 推荐）
curl -X POST http://localhost:5010/api/business/dyndata/search ^
  -H "Content-Type: application/json" ^
  -d "{\"table\":\"Student\",\"page\":1,\"size\":20,\"filter\":{\"Name\":{\"op\":\"like\",\"value\":\"张\"}}}"

# 新增 / 更新 / 删除
curl -X POST http://localhost:5010/api/business/dyndata/insert -H "Content-Type: application/json" -d "{\"table\":\"Student\",\"data\":{\"Name\":\"王五\",\"Age\":22}}"
curl -X POST http://localhost:5010/api/business/dyndata/update -H "Content-Type: application/json" -d "{\"table\":\"Student\",\"data\":{\"Id\":1,\"Name\":\"张三改\"}}"
curl -X POST http://localhost:5010/api/business/dyndata/delete -H "Content-Type: application/json" -d "{\"table\":\"Student\",\"keys\":{\"Id\":1}}"
```

### 方式 C：通用辅助 API

| API | 用途 |
|-----|------|
| `GET /api/dyncommon/emojis?q=笑` | Emoji 搜索（内置 1914 个，含中英文/分类） |
| `GET /api/dyncommon/options?table=Student&valueField=Id&textField=Name` | 通用下拉选项 |
| `GET /api/dyncommon/dicts?type=xxx` | 字典数据 |
| `GET /api/dyncommon/tablelist?table=Student` | 表数据下拉分页 |
| `POST /api/dyncommon/upload` | 文件上传 |

## 7. 开发第一个自定义组件

组件**代码优先落在 Razor View**，DB 只存元数据。组件命名规范：

- Element UI 体系 → `DynElXxx`（如 `DynElInput`）
- 公共体系 → `DynXxx`（如 `DynText`、`DynForm`）

### 步骤 1：新建 cshtml

在 `src/VueLibV4.Web/Areas/Component/Views/ElementUI/MyTag.cshtml` 按三段标记编写：

```razor
@model VueLibV4.Web.Dtos.ComponentViewModel
@{ Layout = null; }

<!--TEMPLATE_START-->
<el-tag :type="comoptions.type || 'primary'">{{ comoptions.text || '标签' }}</el-tag>
<!--TEMPLATE_END-->

<!--SCRIPT_START-->
export default {
  name: "DynElMyTag",
  props: {
    comoptions: Object, labeloptions: Object, itemoptions: Object,
    comlisteners: Object, slots: Object, childrenctrls: Array, modelname: String
  }
};
<!--SCRIPT_END-->

<!--STYLE_START-->
.my-tag { margin: 2px; }
<!--STYLE_END-->
```

> `.cshtml` 改完**刷新浏览器即生效**：项目启用了 `AddRazorRuntimeCompilation()`，
> 且 csproj 中 `RazorCompileOnBuild=false` / `RazorCompileOnPublish=false`，视图不编译进 dll。

### 步骤 2：注册 ComponentMeta

在 `Data/component-meta.sql` 追加（或直接写库）：`ComponentName=DynElMyTag`、`LoadUrl=/api/component/define/DynElMyTag`、`PropsMeta`（右侧属性面板 schema）、`DefaultConfigJson`（拖入画布的默认配置）。

### 步骤 3：验证

```bash
curl "http://localhost:5010/api/component/define/DynElMyTag"
```

返回从 cshtml 提取的 template / script / style，设计器组件库刷新后即可拖用。

## 8. 切换 SQL Server（可选）

编辑 `appsettings.json`：

```json
{
  "ConnectionStrings": {
    "PlatformDb": "Server=localhost;Database=VueLibV4Platform;Trusted_Connection=True;TrustServerCertificate=True;",
    "BusinessDb": "Server=localhost;Database=VueLibV4Business;Trusted_Connection=True;TrustServerCertificate=True;"
  },
  "Db": { "Provider": "SqlServer" }
}
```

> ⚠️ `Data/*.sql` 种子脚本为 SQLite 方言（`INTEGER PRIMARY KEY AUTOINCREMENT` / `datetime('now','localtime')`），
> 切 SQL Server 需自行改写建表语句。建议先用 SQLite 跑通。

## 9. 常见问题

**Q: 启动端口对不上？**
A: 本文档统一用 5010，请带 `--urls http://localhost:5010` 启动，或修改 `appsettings.json` 的 `Urls`。

**Q: 改了 `.cshtml` 组件不生效？**
A: 确认以 `dotnet run`（开发方式）运行并硬刷新浏览器（Ctrl+F5）。dyn 模块 JS 自带版本号；dyn.css 已加 `asp-append-version`，文件改动后 URL 哈希自动更新。

**Q: 组件库为空？**
A: 访问 `/api/component/list` 检查。为空则说明 `ComponentMeta` 种子未执行，删除 `bin/.../App_Data/Platform.db` 重启即可重建。

**Q: 设计器里拖不动组件？**
A: 先确认拖的是「容器」外层而不是 input/button 本身（交互元素默认 filter）；再看浏览器控制台是否有 JS 加载失败。嵌套容器的拖拽冲突已在 `dyn-designer-sortable.js` 修复（直接子元素隔离 + 透明包装层不重复初始化）。

**Q: 如何关闭 evaljs 动作（安全加固）？**
A: 在 `dyn-lib.js` 引入之前加：

```html
<script>window.DYN_LIB_CONFIG = { disableEvalJs: true, loadLayui: false };</script>
```

**Q: 平台库想重置怎么办？**
A: 停止站点 → 删除 `bin/Debug/net8.0/App_Data/Platform.db`（和 Business.db）→ 重新启动，自动全新初始化。
