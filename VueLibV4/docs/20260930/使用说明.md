> 文档版本：2026-09-30
> 面向开发者的功能手册：API、页面操作、组件开发、三屏积木、动作与校验、前端配置。

## 1. API 接口

### 1.1 统一信封

平台域 / 业务域统一返回：

```json
{
  "code": 0,
  "msg": "ok",
  "data": { },
  "dyn-actions": [ ]
}
```

- `code: 0` 成功；非 0 失败，`msg` 为错误描述。
- `data` 内数据行保持数据库列名原样（**PascalCase**，如 `row.Name`、`c.Icon`、`sc.IsActive`）。
- `dyn-actions`：**后端下发的前端动作链**（如保存成功后刷新列表区块、关闭弹窗、toast 提示），前端 `postback/updateEl/reload` 收到后自动按序执行，Controller 无需写 JS。服务端用 `ApiResult.Ok(data).WithActions(...)` 挂载。

组件接口（`ComponentController`）为历史兼容的另一套信封：`{ success, message, data }`。

### 1.2 免模型动态 CRUD

平台有两套同构接口：

| 前缀 | 定位 | 端点 |
|------|------|------|
| `/api/business/dyndata` | 完整版（业务域/项目库） | tables / columns / meta / page / search / get / insert / update / delete / save |
| `/api/platform/dyndata` | 精简版（三屏模板引擎内部使用） | meta / search / get / save / delete |

#### 列出表与元数据

```
GET /api/business/dyndata/tables?project=proj-code
GET /api/business/dyndata/meta?table=Student
GET /api/business/dyndata/columns?table=Student
```

`project` 可传 DynProject 的 Code 或 Id，缺省使用 BusinessDb。

#### 分页查询

```
POST /api/business/dyndata/search
Content-Type: application/json

{
  "table": "Student",
  "project": "proj-code",
  "page": 1,
  "size": 20,
  "filter": {
    "Name": { "op": "like", "value": "张" },
    "Age":  { "op": "gt", "value": 18 },
    "__orderby": "Id desc"
  }
}
```

- 直接写字段值 = 精确匹配（eq）。
- 操作符 `op`：`eq / ne / gt / ge / lt / le / like / in / between`。
- 返回：`{ total, page, size, rows }`（在 `data` 内）。
- GET 简易形式：`GET /api/business/dyndata/page?table=Student&page=1&size=20`。

#### 写入

```
POST /api/business/dyndata/insert     { "table": "Student", "data": { ... } }
POST /api/business/dyndata/update     { "table": "Student", "data": { "Id": 1, ... } }   // 必须含主键
POST /api/business/dyndata/save       // upsert：有主键更新，无主键新增（模板引擎默认用这个）
POST /api/business/dyndata/delete     { "table": "Student", "keys": { "Id": 1 } }
```

### 1.3 平台元数据 CRUD

所有平台控制器（desktopshortcut / desktopsolution / sysmenu / dynproject / dyndict / dynactionhelper / dyntemplate / dynwebpage / pagesetting / dyncom / componentmeta）共享：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/platform/{资源}/all` | 全部启用记录，支持父级/Code 过滤参数 |
| GET | `/api/platform/{资源}/get?id=` 或 `&code=` | 单条 |
| POST | `/api/platform/{资源}/save` | 新增或更新（Id≤0 新增） |
| POST | `/api/platform/{资源}/delete` | `{ "Id": 1 }` |

特例：

- `POST /api/platform/dynproject/test`：测试项目连接串。
- `GET /api/platform/dynactionhelper/script`：输出前端注册脚本。
- `GET /api/platform/dynwebpage/render?code=&id=`：取动态页运行配置。

### 1.4 组件接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/component/list` | 组件清单（DB + Razor 扫描合并） |
| GET | `/api/component/define/{name}` | 单组件定义（template/script/style 三段） |

### 1.5 通用辅助接口（DynCommonController）

| 接口 | 说明 | 主要参数 |
|------|------|---------|
| `GET /api/dyncommon/emojis` | Emoji 搜索（内置 1914 个，中英名/分组） | `q=关键字` |
| `GET /api/dyncommon/options` | 通用下拉选项 | `project&table&valueField=Id&textField=Name`，支持过滤 |
| `GET /api/dyncommon/dicts` | 字典数据 | `type=字典类型` |
| `GET /api/dyncommon/tablelist` | 表数据下拉分页 | `project&table&page&pageSize` |
| `POST /api/dyncommon/upload` | 文件上传 | multipart `file` |

## 2. 页面与设计器操作

### 2.1 工作台桌面 `/Platform/Page/Desktop`

- 桌面图标 / 开始菜单数据来自 **SysMenu**（树形，IsAddToDesktopRoot / IsAddToStartMenu 控制投放）与 DesktopShortcut。
- 双击图标开窗：`TargetType=Iframe` 内嵌窗口（可拖拽/最小化/最大化/关闭）；`FullScreen` 整页跳转。
- 菜单管理在 `/Platform/Mgmt/SysMenuMgmt`，快捷方式管理在 `/Platform/Mgmt/DesktopShortcut`（Emoji 图标可搜索选择）。

### 2.2 页面设计器 `/Platform/Page/Designer`

四分区：

```
┌─────────────────────────────────────────────────────────┐
│ TopBar：页面名 / 保存 / 预览 / JSON / 撤销重做            │
├──────────┬─────────────────────────────┬─────────────────┤
│ LeftPanel│           Canvas            │   RightPanel    │
│ 组件库   │                             │  属性 / 样式     │
│ 模板     │      DynCom 组件树画布       │  事件 / 校验     │
│ 结构树   │                             │  JS / 配置元    │
└──────────┴─────────────────────────────┴─────────────────┘
```

**画布交互：**

- 左侧组件库拖入：clone 模式，自动按 DefaultConfigJson 创建组件并分配 `__uid`。
- 嵌套：往容器组件内部拖即可；支持任意层级。
- 选中：单击组件（onClickCapture），蓝色悬浮框 + 顶部工具条（复制/删除/层级操作），右侧属性联动。
- 拖拽反馈：淡蓝候选框 / 绿色可放 / 红色禁放；空容器显示「＋ 拖放组件到此处」。
- 结构树：左侧树可选中、查看层级路径；底部状态栏显示组件路径面包屑。
- 嵌入模式：`?embed=1`，独立 HTML 壳，通过 postMessage 与宿主（DynDesignerDialog）通信。

**属性面板**由 ComponentMeta.PropsMeta schema 驱动（input/textarea/select/color/number/boolean/slider/json 等控件）。

### 2.3 页面生成向导 `/Platform/Page/PageGen`

选项目 → 选业务表 → 勾选字段 → 生成。产出：3 条 PageSetting（Filter/List/Detail）+ 1 条 DynWebPage（绑定三屏），随后可在 DynWebPageMgmt 打开，或进设计器微调。

### 2.4 DSL 编辑器 `/Platform/Page/Dsl`

类 Markdown 的轻量页面 DSL：左栏 DSL 文本 / 中栏 JSON / 右栏实时预览三栏联动，适合熟练用户快速搭页面。

### 2.5 运行时入口

| 入口 | 用途 |
|------|------|
| `/Platform/Page/WebPageRender?code=xxx` | 按页面 Code 渲染 DynWebPage.PageJson 组件树 |
| `/Platform/Page/DynWebPage?id=x` | 模板引擎：实例参数 + 模板外壳 + 三屏 PageSetting 拼装渲染 |
| `/Platform/Page/DynDetail?settingId=x&bizId=1&table=Student` | Detail 屏独立页/弹窗片段（新增/编辑表单） |
| `/Platform/Page/DetailModal?id=x&rowId=1` | 弹窗页面片段，供列表页 fetchPartial 注入 |

## 3. 组件开发

### 3.1 命名与放置

| 体系 | 命名 | 目录 |
|------|------|------|
| Element UI | `DynElXxx` | `Areas/Component/Views/ElementUI/` |
| 公共 | `DynXxx` | `Areas/Component/Views/Common/` |

文件名（ViewPath）与组件名可不同，但建议保持一致便于查找。

### 3.2 cshtml 三段标记

```razor
@model VueLibV4.Web.Dtos.ComponentViewModel
@{ Layout = null; }

<!--TEMPLATE_START-->
<el-input
  :model-value="model[modelname]"
  @update:model-value="v => $emit('update:modelValue', v)"
  :placeholder="comoptions.placeholder"
  :disabled="comoptions.disabled"
  clearable />
<!--TEMPLATE_END-->

<!--SCRIPT_START-->
export default {
  name: "DynElInput",
  props: {
    modelname: String,
    comoptions: Object,
    labeloptions: Object,
    itemoptions: Object,
    comlisteners: Object,
    slots: Object,
    childrenctrls: Array
  },
  emits: ["update:modelValue"]
};
<!--SCRIPT_END-->

<!--STYLE_START-->
/* 可选 */
<!--STYLE_END-->
```

容器组件还需在 `_BaseLayout.cshtml` 的基础布局上挂 children 插槽；容器组件只在**非透明模式**（真实组件层）初始化 Sortable，勿在透明包装层重复绑定。

### 3.3 注册元数据（ComponentMeta）

关键字段：

| 字段 | 说明 |
|------|------|
| ComponentName | Vue 全局组件名（DynElXxx） |
| Label / Category / Icon | 组件库展示（分类：容器/表单/基础/通用） |
| LoadUrl | `/api/component/define/组件名` |
| ViewPath | cshtml 相对路径 |
| IsContainer | 是否容器 |
| AcceptAll / AllowDrop | 允许放入的子组件类型；`["*"]` 表示全部 |
| PropsMeta | 右侧属性面板 schema（JSON 数组） |
| DefaultConfigJson | 拖入画布时的默认 cfg |

PropsMeta 示例：

```json
[
  { "key": "placeholder", "label": "占位符", "type": "input", "group": "基础" },
  { "key": "disabled", "label": "禁用", "type": "boolean", "group": "基础" },
  {
    "key": "size", "label": "尺寸", "type": "select", "group": "基础",
    "options": [
      { "label": "大", "value": "large" },
      { "label": "默认", "value": "default" },
      { "label": "小", "value": "small" }
    ]
  },
  { "key": "modelname", "label": "绑定字段", "type": "input", "group": "数据" }
]
```

### 3.4 设计器/运行时双模式

同一组件通过注入的 designMode 标志区分：设计态显示 overlay、禁止真实提交；运行态正常交互。组件内部不要假设自己总在表单里——容器、展示型组件同样走这套渲染。

## 4. 三屏积木（Filter / List / Detail）

- **PageSetting**：区块配置。Filter/Detail 的 ConfigJson 是 DynCom 组件树，DefaultJson 分别是查询条件骨架（`{字段:{op,value}}`）与表单初始值；List 的 ConfigJson 是 `{columns:[...]}`。
- **RenderMode**：`Front` = 前端 DynCom 动态渲染；`Back` = Razor 局部视图（PartialPath）。
- **DynTemplate**：外壳视图（如 `Views/DynTemplates/FilterListCrud.cshtml`、`TreeDetail.cshtml`、`TriScreenBlocks.cshtml`），定义区块拼装与流转。
- **DynWebPage**：实例参数（TableName、ListUrl/AddUrl/EditUrl/DeleteUrl、Filter/List/DetailPageSettingId、主从外键等）。
- **Block**：`Views/DynBlocks/FilterBlock.cshtml`、`ListBlock.cshtml`、`DetailBlock.cshtml`，各带 createApp，经共享 scope 与根 app 协作。

详细字段、dynmodel 注入机制、挂载顺序与踩坑说明见仓库文档：`docs/动态页面与三屏积木体系规范.md`。

## 5. 动作系统

### 5.1 内置动作

| code | 说明 | 参数要点 |
|------|------|---------|
| postback / postdata | 调后端接口 | url / method / data / params |
| confirm-postdata | 确认后提交 | message + url + data |
| reload | 刷新 | — |
| open | 开窗/跳转 | url / target / 窗口尺寸 |
| close | 关窗 | — |
| updateel | 更新 DOM | selector / html / text |
| evaljs | 执行 JS（可全局关闭） | script |
| load | 动态加 JS/CSS | url / type |
| setVueModel | 写响应式 model（lodash _.set） | modelname / value |
| showmessage | ElMessage 提示 | message / type / duration |
| redirect | 页面跳转 | url |

### 5.2 属性委托

```html
<!-- 点击执行入库/内置动作 -->
<el-button data-dyn-click-postdata='{"url":"/api/...","data":{}}'>保存</el-button>

<!-- 页面初始化时执行 -->
<div data-dyn-init-setVueModel='{"modelname":"now","value":"2026-09-30"}'></div>
```

支持事件：click / dblclick / change / focus / select / mouseover 等。

### 5.3 服务端下发动作链（dyn-actions）

Controller 保存成功后可直接下发前端动作，无需在页面写回调：

```csharp
return ApiResult.Ok(new { id })
    .WithActions(
        DynJavaScript.Toast("保存成功"),
        DynJavaScript.ReloadBlock("list"),
        DynJavaScript.CloseLayer());
```

### 5.4 script 上下文与事件总线

```javascript
// 入库 script 动作可用
$action   // 动作定义
$args     // 属性传入参数
$ctx      // { element, event, model, pageCtx }
$api      // axios 实例（自动带 X-Requested-With）

// 跨组件通信
DynBus.emit("saved", { id: 1 });
DynBus.on("saved", d => { /* ... */ });
```

## 6. 校验器

cfg 的 `validators` 数组：

```json
[
  { "type": "required", "message": "必填" },
  { "type": "pattern", "pattern": "^1[3-9]\\d{9}$", "message": "手机号格式不正确" },
  { "type": "min", "min": 0, "message": "不能小于0" },
  { "type": "custom", "script": "return v && v.length >= 2;", "message": "至少2个字符" }
]
```

内置：required / email / phone / pattern / min / max / length / custom。
前端 API：`DynValidator.validate(validators, value, form)` 返回错误数组；`DynValidator.toRules(validators)` 转 Element Plus 表单 rules。

## 7. 前端配置

### 7.1 DYN_LIB_CONFIG（必须先于 dyn-lib.js 赋值）

```html
<script>
  window.DYN_LIB_CONFIG = {
    loadLodash: true,
    loadElementPlus: true,
    loadLayui: false,       // 不用 Layui 时关掉省体积
    loadCodemirror: false,
    loadTailwind: true,
    loadAxios: true,        // 使用 wwwroot/lib/axios.min.js
    disableEvalJs: false    // true = 全局关闭 evaljs
  };
</script>
<script src="/dyn/dyn-lib.js" asp-append-version="true"></script>
```

### 7.2 多 App 共享 scope

```html
<div data-dyn-shared-scope="bizPage"
     data-dyn-scope-json='{"form":{},"pageInfo":{"PageIndex":1}}'>
  <div data-dyn-use-scope="bizPage" id="filterBlock"><!-- 筛选区 app --></div>
  <div data-dyn-use-scope="bizPage" id="listBlock"><!-- 列表区 app，共享同一 model --></div>
</div>
```

JS 中反查：`window.dyn.getScopeModel(el)`。

### 7.3 静态资源缓存约定

- dyn 模块 JS：dyn-lib.js 以统一 `v=版本号` 加载，升级时改 `DynLib.version`。
- dyn.css：三个布局均加 `asp-append-version="true"`，文件内容变化后 URL 自动带哈希。
- 开发期强刷：Ctrl+F5。

## 8. 日常运维速查

```powershell
# 启动（固定 5010）
dotnet run --project src/VueLibV4.Web --urls http://localhost:5010

# 编译
dotnet build src/VueLibV4.Web/VueLibV4.Web.csproj

# 重置数据库（停站点后）
Remove-Item src/VueLibV4.Web/bin/Debug/net8.0/App_Data/*.db
# 再启动即全新初始化
```

- 改 `.cshtml` 组件 → 刷新浏览器（运行时编译，无需重启）。
- 改 `wwwroot/dyn/*.js` → 升 `DynLib.version` 或 Ctrl+F5。
- 改 `wwwroot/dyn/dyn.css` → 自动哈希，Ctrl+F5 即可。
- 新增种子数据 → 放到 `Data/seed-extra.sql`（幂等），重启自动执行。
