# VueLibV4 使用说明

> 面向开发者的功能手册：API 接口、页面使用、组件系统、动作系统。

---

## 1. API 接口

### 1.1 统一信封格式

**平台域 / 业务域 API** 使用统一信封：

```json
{ "code": 0, "msg": "ok", "data": { ... } }
```

- `code: 0` = 成功
- `code: 非0` = 失败，`msg` 含错误描述
- `data` = 业务数据（类型因接口而异）

**ComponentController** 使用另一套信封（历史兼容）：

```json
{ "success": true, "message": "ok", "data": { ... } }
```

> ⚠️ 前端需分别处理两种格式，见"问题与改进"第 1 节。

### 1.2 免模型动态 CRUD 核心 API

这是本平台最核心的接口——**只要知道表名即可完成增删改查**。

#### 列出表

```
GET /api/business/dyndata/tables?project=proj-school
```

- `project`：可选，DynProject 的 Code 或数字 Id，缺省用 BusinessDb
- 返回：`["Student", "Course", ...]`

#### 获取表元数据

```
GET /api/business/dyndata/meta?table=Student
```

返回：

```json
{
  "table": "Student",
  "columns": [
    { "Name": "Id", "DataType": "INTEGER", "IsPrimaryKey": true, "IsNullable": false },
    { "Name": "Name", "DataType": "NVARCHAR(100)", "IsPrimaryKey": false, "IsNullable": false },
    { "Name": "CreateTime", "DataType": "DATETIME2", "IsPrimaryKey": false, "IsNullable": true }
  ],
  "primaryKeys": ["Id"]
}
```

#### 分页查询（GET）

```
GET /api/business/dyndata/page?table=Student&page=1&size=20&filter={"Name":"张"}
```

- `page`：页码，默认 1
- `size`：每页条数，默认 20，最大 200
- `filter`：JSON 字符串，支持精确匹配和条件操作符

#### 分页查询（POST，推荐）

```
POST /api/business/dyndata/search
Content-Type: application/json

{
  "table": "Student",
  "project": "proj-school",
  "page": 1,
  "size": 20,
  "filter": {
    "Name": "张",
    "Age": { "op": "gt", "value": "18" },
    "__orderby": "Id desc"
  }
}
```

返回：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "total": 12,
    "page": 1,
    "size": 20,
    "rows": [
      { "Id": 1, "Name": "张三", "Age": 20, "ClassName": "一班", "CreateTime": "2024-01-01" }
    ]
  }
}
```

#### 新增

```
POST /api/business/dyndata/insert
Content-Type: application/json

{
  "table": "Student",
  "project": "proj-school",
  "data": { "Name": "李四", "Age": 19, "ClassName": "二班" }
}
```

自增主键会自动回填到 `CreateTime` 字段（若列存在），并返回新生成的 Id。

#### 更新

```
POST /api/business/dyndata/update

{
  "table": "Student",
  "data": { "Id": 1, "Name": "张三（改）", "Age": 21 }
}
```

必须包含主键值，否则返回"缺少主键值"错误。

#### 删除

```
POST /api/business/dyndata/delete

{
  "table": "Student",
  "keys": { "Id": 1 }
}
```

### 1.3 平台元数据 API

所有平台控制器（DesktopShortcut / DynProject / DynActionHelper / DynTemplate / DynWebPage / DynCom / ComponentMeta / DynDict / DynTemplate）共享相同的 CRUD 模式：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/all` | 全部已启用记录，可按父级 Id/Code 过滤 |
| GET | `/get?id=xxx` | 按 Id 或 Code 查单条 |
| POST | `/save` | 新增或更新（Id≤0 新增，Id>0 更新） |
| POST | `/delete` | `{ "Id": 1 }` 删除单条 |

**DynProject 特有**：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/test` | 测试连接串是否可用 `{ "ConnectionString": "..." }` |

**DynActionHelper 特有**：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/script` | 生成前端注册脚本（纯文本） |

**DynWebPage 特有**：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/render?id=xxx&code=xxx` | 运行时渲染数据（返回 config JSON） |

## 2. 页面使用

### 2.1 桌面工作台 `/Platform/Page/Desktop`

- **桌面图标**：双击打开，关联 `/api/platform/desktopshortcut/all` 的快捷方式
- **窗口**：iframe 模式打开，支持拖动、最小化、最大化、关闭
- **开始菜单**：左下角按钮，按 DesktopSolution 分组展示
- **右键菜单**：刷新 / 跳转设计器 / CRUD Demo
- **任务栏**：窗口切换 + 时钟

### 2.2 页面设计器 `/Platform/Page/Designer`

**三栏布局**：

```
┌──────────────────────────────────────────────────────────┐
│ TopBar: 页面名 / 保存 / 预览 / 导出模板 / JSON 编辑器     │
├──────────┬──────────────────────────────┬────────────────┤
│ LeftPanel│          Canvas              │  RightPanel    │
│          │                              │                │
│ 组件库   │    画布（组件拖放区域）       │  属性面板      │
│ 模板     │                              │  事件          │
│ 结构树   │                              │  校验          │
│          │                              │  JS            │
└──────────┴──────────────────────────────┴────────────────┘
```

**LeftPanel Tab**：
- 组件库：按 Category 分组展示 ComponentMeta
- 模板：DynTemplate 列表
- 结构树：当前页面 cfg 的树形视图

**RightPanel Tab**：
- 属性：从 ComponentMeta.PropsMeta 自动渲染
- 样式：CSS class / style 编辑
- 事件：绑定 dyn-action
- 校验：dyn-validator 规则
- JS：自定义脚本

**画布操作**：
- 从组件库拖入 → 自动创建默认 cfg
- 点击组件 → 选中 + 悬浮高亮框 + 属性联动
- 拖拽排序 → SortableJS 实现
- `Ctrl+Z` / `Ctrl+Y` 预留

### 2.3 动态页面运行时 `/Platform/Page/WebPageRender?code=student-manage`

1. 前端从 URL 取 `code` 或 `id`
2. `GET /api/platform/dynwebpage/render?id=xxx` 返回 `{config, configjson}`
3. `DynCore.normalize(config)` → 补全默认值
4. `DynCore.mount(cfg, container)` → 递归渲染真实组件

### 2.4 Demo 页面

| 路径 | 演示内容 |
|------|---------|
| `/Platform/Page/Demo/Crud` | DynCrudPage 组件 + 学生表 CRUD 完整流程 |
| `/Platform/Page/Demo/Grid` | DynGridContainer 栅格布局（12 列 / 响应式） |
| `/Platform/Page/Demo/Combination` | DynCombination 组合组件属性展开 |

| `/Platform/Page/Demo/CodeMirror` | DynCodeMirror 代码编辑器（SQL / JS / HTML 模式） |

## 3. 组件系统

### 3.1 组件创建流程

**方式一：Razor View 定义（推荐，可版本化、可调试、IDE 高亮）**

1. 在 `Areas/Platform/ElementUI/` 或 `Areas/Platform/Common/` 下创建 `.cshtml` 文件
2. 按三段标记格式写 template + script + style
3. 在 ComponentMeta 表中注册：
   - `ComponentName` = 文件名（不含扩展名）
   - `ViewPath` = `Areas/Platform/ElementUI/你的组件名.cshtml`
   - `LoadUrl` = `/api/component/define/你的组件名`（动态加载地址）
   - `PropsMeta` = 属性面板 schema（JSON）
   - `DefaultConfigJson` = 拖入画布时的初始 cfg

**方式二：DB 定义（快速原型）**

直接在 ComponentMeta 的 TemplateContent / ScriptContent / StyleContent 字段写内容，ViewPath 留空即可。

### 3.2 Razor 组件文件模板

```razor
@model VueLibV4.Web.Dtos.ComponentViewModel
@{ Layout = null; }

<!--COMPONENT_TYPE:0-->
<!--ROUTE_PATH:/demo/mycomp-->

<!--TEMPLATE_START-->
<div class="my-comp" :class="$attrs.class" :style="$attrs.style">
  <el-input v-if="comoptions.modelname"
            :model-value="modelname"
            @update:model-value="v => $emit('update:modelValue', v)"
            :placeholder="comoptions.placeholder || '请输入'"
            :disabled="comoptions.disabled" />
</div>
<!--TEMPLATE_END-->

<!--SCRIPT_START-->
export default {
  name: "ComInput",
  props: {
    modelname: String,
    comoptions: Object,
    labeloptions: Object,
    itemoptions: Object,
    comlisteners: Object,
    slots: Object,
    childrenctrls: Array
  },
  emits: ['update:modelValue'],
  setup(props, ctx) {
    return {};
  }
};
<!--SCRIPT_START-->

<!--STYLE_START-->
.my-comp { padding: 4px; }
<!--STYLE_END-->
```

### 3.3 ComponentMeta.PropsMeta 格式

属性面板 schema 驱动设计器右侧面板的自动渲染：

```json
[
  {
    "key": "placeholder",
    "label": "占位符",
    "type": "input",
    "group": "基础"
  },
  {
    "key": "disabled",
    "label": "禁用",
    "type": "boolean",
    "group": "基础",
    "default": false
  },
  {
    "key": "label",
    "label": "标签",
    "type": "input",
    "group": "布局",
    "show": { "field": "show", "op": "eq", "value": true }
  },
  {
    "key": "modelname",
    "label": "绑定字段",
    "type": "input",
    "group": "数据"
  }
]
```

type 支持：`input` / `textarea` / `select` / `color` / `number` / `boolean` / `slider` / `json`

### 3.4 cfg 配置树常用选项

| 路径 | 说明 |
|------|------|
| `comoptions.xxx` | 组件专属业务属性 |
| `labeloptions.show` / `.label` | 标签显示开关 / 标签文本 |
| `itemoptions.class` / `.style` | 外层容器 class / style |
| `comlisteners.xxx` | @事件 → 动作 code（如 `"change": "setVueModel"`） |
| `modelname` | v-model 绑定字段名 |
| `slots.default` / `slots.header` | 插槽内容（cfg 数组） |
| `childrenctrls` | 子组件 cfg 数组 |
| `extendinfo.vif` | v-if 条件表达式 |
| `extendinfo.vfor` | v-for 循环表达式 |
| `extendinfo.ref` | Vue ref 名称 |

## 4. 动作系统

### 4.1 内置动作

| code | 类型 | 说明 | 参数 |
|------|------|------|------|
| `postback` | api | 表单提交到后端 | `{url, method?, data?, params?}` |
| `postdata` | api | 同 postback，支持模板变量 | `{url, data}` |
| `confirm-postdata` | chain | 确认对话框 → 提交 | `{url, data, message}` |
| `reload` | script | 刷新页面 | — |
| `open` | url | 打开新窗口 / 跳转到指定 URL | `{url, target?}` |
| `close` | script | 关闭当前窗口 | — |
| `updateel` | script | 更新指定 DOM 元素内容 | `{selector, html, text}` |
| `evaljs` | script | 执行自定义 JS | `{script}` |
| `load` | script | 动态加载 JS / CSS 资源 | `{url, type?}` |
| `setVueModel` | script | 用 lodash `_.set` 写响应式 model | `{modelname, value}` |
| `showmessage` | script | ElementPlus ElMessage 提示 | `{message, type?, duration?}` |
| `redirect` | url | 页面内跳转 | `{url}` |

### 4.2 属性委托方式

```html
<!-- 事件委托：click → postdata -->
<button data-dyn-click-postdata='{"url":"/api/save","data":{"name":"{{model.name}}"}}'>保存</button>

<!-- 初始化委托：页面加载时执行 -->
<div data-dyn-init-setVueModel='{"modelname":"currentDate","value":"2024-01-01"}'></div>

<!-- 支持的事件：click / dblclick / change / select -->
```

### 4.3 动作链

```json
{
  "code": "confirm-save",
  "actionType": "chain",
  "script": {
    "steps": [
      { "action": "showmessage", "when": "$args.step === 1" },
      { "action": "confirm-postdata", "when": "$args.step === 2" },
      { "action": "reload", "when": "$result.success" }
    ]
  }
}
```

### 4.4 自定义脚本上下文

```javascript
// script 类型动作可访问的上下文
$action  // 当前动作元数据
$args    // HTML 属性传入的参数对象
$ctx     // 执行上下文（含 element / event / model / pageCtx）
$api     // axios 实例
// 内置 lodash / moment / ElementPlus（若加载）
```

### 4.5 事件总线

```javascript
// 组件 A 发布
DynBus.emit('studentSaved', { id: 1 });

// 组件 B 订阅
DynBus.on('studentSaved', (data) => {
  console.log('学生已保存:', data.id);
});
```

## 5. 校验器

### 5.1 内置规则

| type | 说明 | 参数 |
|------|------|------|
| `required` | 必填 | — |
| `email` | 邮箱格式 | — |
| `phone` | 手机号（大陆） | — |
| `pattern` | 正则匹配 | `{ pattern: "^1[3-9]\d{9}$" }` |
| `min` | 最小值 | `{ min: 0 }` |
| `max` | 最大值 | `{ max: 100 }` |
| `length` | 最小长度 | `{ length: 6 }` |
| `custom` | 自定义脚本 | `{ script: "return v && v.length >= 2;" }` |

### 5.2 使用

```json
{
  "validators": [
    { "type": "required", "message": "姓名必填" },
    { "type": "pattern", "pattern": "^1[3-9]\\d{9}$", "message": "手机号格式不正确" },
    { "type": "custom", "script": "return v && v.length >= 2;", "message": "至少2位" }
  ]
}
```

运行时调用 `DynValidator.validate(validators, value, form)` 返回错误数组，或 `DynValidator.toRules(validators)` 转为 ElementPlus el-form rules 格式。

## 6. 模板导入导出

### 6.1 导入：ElementPlus Vue Template → DynCom JSON

```javascript
var html = `
<el-form :model="form" label-width="80px">
  <el-form-item label="姓名">
    <el-input v-model="form.name" placeholder="请输入姓名" />
  </el-form-item>
</el-form>
`;
var cfgs = DynTemplate.importTemplate(html);
// 返回 DynCom cfg 数组，可直接粘到设计器 JSON 编辑器
```

### 6.2 导出：DynCom JSON → Vue Template

```javascript
var vueHtml = DynTemplate.exportTemplate(pageCfg);
// 返回 ElementPlus Vue Template 字符串
```

## 7. 前端配置

### 7.1 DYN_LIB_CONFIG

在页面 `<script>` 中覆盖默认值（必须在 `dyn-lib.js` 之前引入）：

```html
<script>
  window.DYN_LIB_CONFIG = {
    loadLayui: false,          // 不加载 Layui（节省体积）
    loadElementPlus: true,     // 默认 true
    loadTailwind: false,       // 不加载 Tailwind
    loadCodemirror: false,     // 不加载 CodeMirror
    loadLodash: true,          // 默认 true
    loadAxios: true,           // 默认 true（需 wwwroot/lib/axios.min.js 存在）
    disableEvalJs: true        // 全局关闭 evaljs 动作（安全加固）
  };
</script>
```

### 7.2 多 App 嵌套 + scope 共享

```html
<!-- 根元素声明共享 scope -->
<div data-dyn-shared-scope="myForm"
     data-dyn-scope-json='{"form":{"name":"","age":0}}'>

  <!-- 每个分区独立 createApp，通过 data-dyn-use-scope 指向同一份 model -->
  <div id="left" data-dyn-init-createapp data-dyn-use-scope="myForm">
    <!-- Vue 代码里通过 model.form.name 读写 -->
  </div>

  <div id="right" data-dyn-init-createapp data-dyn-use-scope="myForm">
    <!-- 同一 reactive 对象 -->
  </div>
</div>
```
