# VueLibV4 快速开始

> 文档版本：2026-10-14 · 适用代码库：VueLibV4（.NET 8 / SQLite）
> 从零到跑通，预计 3 分钟。

---

## 1. 平台是什么

VueLibV4 是一个 **ASP.NET Core 8 + Vue 3（UMD 无打包）的企业级低代码平台**：

- **免模型动态 CRUD**：知道表名即可分页查询 / 新增 / 更新 / 删除，后端不需要为每张表建实体。
- **可视化页面设计器**：拖拽组件 → 配置属性 → 保存为 DynWebPage → 运行时动态渲染。
- **三屏积木体系 V2**：FilterApp / ListApp / DetailApp / TreeApp 四个独立 BlockApp，通过 `DynEventBus`（ExecId）通信，模板只管组装。
- **组件双定义源**：Razor View（`.cshtml`，代码优先）+ 数据库 `ComponentMeta`（回退）。
- **双桌面壳**：Windows 风格工作台桌面 + macOS 拟物风格桌面。
- **统一动作系统**：`dyn-click="ActionHelper.Submit|ActionHelper.Toast('保存成功')"` 管道语法，所有动作可入库动态注册。

## 2. 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| .NET SDK | 8.0+ | `winget install Microsoft.DotNet.SDK.8` |
| 浏览器 | Chrome / Edge 现代版本 | 设计器依赖 Vue 3.5、SortableJS |
| Node.js | **不需要** | 前端全部 UMD 本地文件，无 npm/打包步骤 |
| 数据库 | **不需要安装** | 默认双 SQLite，首次启动自动建库 |

## 3. 获取代码并运行

```powershell
# 在仓库根目录（VueLibV4.sln 所在目录）
cd E:\Tom\Tool\VueLibV4
dotnet run --project src\VueLibV4.Web --urls http://localhost:5010
```

首次启动时自动完成（全部幂等，可重复启动）：

1. 在 `src/VueLibV4.Web/bin/Debug/net8.0/App_Data/` 下创建两个 SQLite 库：
   - `Platform.db` —— 平台库（25 张表，含组件元数据、页面、权限、菜单、日志）
   - `Business.db` —— 业务库（Student / Course / BusinessDict + 演示数据）
2. 自动执行建表 + 种子数据（组件注册表、模板、演示页面、菜单）。
3. 旧库自动增量迁移（补表、补列、改名、补种子），不删数据。

看到启动日志后浏览器打开 <http://localhost:5010/> 即跳转到工作台桌面。

### 解决方案结构（3 个项目）

```
VueLibV4.sln
└─ src/
   ├─ VueLibV4.Web/        Web 站点（Areas 控制器/视图、Seeder、前端 wwwroot）
   ├─ VueLibV4.Platform/   平台层（25 张表的模型 + Service + 页面生成器）
   └─ VueLibV4.Services/   基础层（DbFactory、免模型 CRUD、Emoji、扩展方法、DI）
```

## 5. 5 分钟建一个 CRUD 页面

### 方式一：页面生成向导（推荐）

1. 打开 `/Platform/Page/PageGen`
2. 选择项目（如 Business）→ 选择表（如 Student）
3. 选择要展示的字段 → 选择表单字段
4. 点击生成 → 自动创建三屏页面（Filter + List + Detail）
5. 在页面实例管理中打开新生成的页面

### 方式二：手写模板（开发人员）

1. 在 `Views/DynTemplates/` 下创建 `.cshtml`
2. 通过 `PartialAsync` 引入 V2 BlockApp：
   ```html
   @await Html.PartialAsync("~/Views/DynBlocks/AppsV2/ListApp.cshtml", new ViewDataDictionary(ViewData) {
       ["ExecId"] = execId, ["TableName"] = tableName, ...
   })
   ```
3. 在 `DynTemplate` 表注册模板记录（Code / Name / ViewPath）
4. 在 PageController 白名单加入模板 Code

## 6. 默认登录

- 平台默认有 1 个管理员账号（SysUser 表）
- 本地开发默认放行（`Dyn:Auth:AllowLocal=true`）
- API 调用可使用 `X-Api-Key` 头（appsettings.json 中 `Dyn:Auth:ApiKey`）
