## 1. 工作台桌面

**路由**：`/Platform/Page/Desktop`

Windows 风格的工作台：
- **桌面图标**：从 `DesktopShortcut` 表读取，双击打开对应页面
- **开始菜单**：从 `SysMenu` 表读取树形菜单，点击跳转
- **任务栏**：显示当前打开的窗口（多页面可同时打开，tab 切换）
- **窗口系统**：支持拖动、最大化、最小化、关闭

macOS 风格桌面 Demo：`/Platform/Page/MacDesktopDemo`

## 2. 页面设计器

**路由**：`/Platform/Page/Designer`

### 2.1 三栏布局

| 区域 | 功能 |
|------|------|
| 左侧组件库 | 按分类列出所有已注册组件（输入、选择、容器、表格、树等） |
| 中间画布 | 拖拽放置组件，支持缩放（0.25~1.5）、标尺、撤销重做（20步） |
| 右侧属性面板 | 编辑选中组件的 label、placeholder、校验规则、事件等 |

### 2.2 核心操作

- **拖拽放置**：从左侧组件库拖到画布
- **选中/编辑**：点击组件，右侧显示属性
- **容器子项管理**：Table/Tabs/Collapse 等容器自动提供增删排序（由 ComponentMeta.designerMeta 驱动）
- **撤销/重做**：Ctrl+Z / Ctrl+Y，或工具栏按钮
- **预览模式**：切换后隐藏所有 Overlay，模拟线上运行效果
- **保存**：页面 JSON 存入 `PageSetting.ConfigJson`

### 2.3 设计态 vs 运行态隔离

- 设计器的选中态、hover、Tab 预览切换 **不写入** 页面 JSON
- 下发运行时自动剔除 `designerMeta`、`designerOperates` 等设计器元信息
- 运行时页面不包含任何设计器代码

## 3. 页面模板体系（V1 / V2）

### 3.1 已有模板清单（21 个）

| Code | 名称 | 架构 | 说明 |
|------|------|------|------|
| `crud-basic` | 基础CRUD页面 | 免 Model | TableName 自动推导接口 |
| `tree-detail` | 树形管理(树+详情) | V1 内联 | 左树内联 + 右 DetailApp |
| **`tree-detail-v2`** | **树形管理V2(树+详情)** | **V2 BlockApp** | **TreeApp + DetailApp + DynEventBus** |
| `filterlist-crud` | 筛选列表CRUD | V1 Block | Filter + List + Detail |
| `filter-list-open-windowV2` | 筛选列表弹窗V2 | V2 布局壳 | 顶筛选 + 列表 + 弹窗详情 |
| `filter-list-drawer-leftV2` | 筛选列表左侧抽屉V2 | V2 布局壳 | 顶筛选 + 列表 + 抽屉编辑 |
| `detail-modal-v2` | 详情弹窗V2 | V2 片段 | layui layer 加载的 DetailApp 片段 |
| `triscreen-blocks` | 三屏积木 | V1 Block | Filter + List + Detail 三屏 |
| `tabs-basic` | 多页签容器 | 片段 | Tab 容器 |
| `list-master-detail` | 列表主从壳 | 布局壳 | 顶筛选 + 左列表 + 右明细 |

### 3.2 V1 vs V2 架构差异

| 维度 | V1 | V2 |
|------|----|----|
| BlockApp 挂载 | `data-dyn-mode="createApp"` 内联 | `dyn-init="createApp"` 独立 partial |
| 通信方式 | `DynBlocks.createBlockHandle` 句柄 + on/send | `window.DynEventBus` + ExecId |
| BlockApp 复用 | 模板内联代码，不可独立复用 | 独立 .cshtml partial，可跨模板复用 |
| 弹窗支持 | 句柄跨 DOM 困难 | ExecId 全局 Map，弹窗脱离 DOM 也能通信 |

## 4. V2 BlockApp 积木体系

### 4.1 四个独立 BlockApp

| BlockApp | 文件 | emit 事件 | 监听事件 |
|----------|------|-----------|----------|
| **FilterApp** | `AppsV2/FilterApp.cshtml` | `search`{payload} | — |
| **ListApp** | `AppsV2/ListApp.cshtml` | `rowClick`{row}、`saved` | `search`、`reload` |
| **DetailApp** | `AppsV2/DetailApp.cshtml` | `saved`{action,row}、`cancel` | `newForm`{preFill}、`editForm`{row} |
| **TreeApp** | `AppsV2/TreeApp.cshtml` | `nodeClick`{row}、`addRoot`{}、`addChild`{preFill} | `reload` |

### 4.2 通信机制：DynEventBus

```
模板根 DOM (execId)
  ├── TreeApp (emit nodeClick/addRoot/addChild)
  └── DetailApp (on newForm/editForm)
  
模板 Scripts 段做事件名转换：
  tree.nodeClick → detail.editForm {row}
  tree.addRoot → detail.newForm {preFill:{}}
  tree.addChild → detail.newForm {preFill}
  detail.saved → tree.reload
```

- **快照补发**：emit 时存 `rootEl.__snap[eventName]`，晚注册的 on 自动读快照补发一次
- **弹窗跨 DOM**：全局 `Map<execId, rootEl>`，弹窗脱离 DOM 也能按 execId 找回

### 4.3 在模板中组装 V2 BlockApp

```html
@{
    var execId = "tdv2-" + Guid.NewGuid().ToString("N");
}
<div class="tr-root" data-exec-id="@execId">
    <div class="tr-pane-left">
        @await Html.PartialAsync("~/Views/DynBlocks/AppsV2/TreeApp.cshtml", 
            new ViewDataDictionary(ViewData) {
                ["ExecId"] = execId,
                ["TableName"] = tableName,
                ["KeyField"] = keyField,
                ...
            })
    </div>
    <div class="tr-pane-right">
        @await Html.PartialAsync("~/Views/DynBlocks/AppsV2/DetailApp.cshtml", 
            new ViewDataDictionary(ViewData) {
                ["ExecId"] = execId,
                ["DetailSettingId"] = detailPsId,
                ...
            })
    </div>
</div>
```

## 5. 动作系统（dyn-click 管道）

### 5.1 语法

```html
<button dyn-click="ActionHelper.Submit">保存</button>
<button dyn-click="ActionHelper.Submit|ActionHelper.Toast('保存成功')|ActionHelper.Reload">提交</button>
<button dyn-click="open" data-dyn-url="/Page/Detail?id=1">打开详情</button>
```

管道用 `|` 分隔，按顺序执行；上一步的结果可通过 `$result` 占位传递。

### 5.2 内置动作

| 动作 | 说明 |
|------|------|
| `submit` / `updateel` | 提交当前表单到 URL，返回 HTML 片段替换目标元素 |
| `postback` | 提交数据到后端，返回 JSON 执行 dyn-actions |
| `reload` | 刷新指定 BlockApp 或容器 |
| `open` / `openwindow` | 打开弹窗（fragment 片段 / iframe 两种模式） |
| `close` / `closewindow` | 关闭最近弹窗 |
| `toast` / `showmessage` | 显示消息提示 |
| `confirm` | 确认对话框 |
| `evaljs` | 执行 JS 表达式 |
| `setparams` | 写参数上下文（shared/local 两种 scope） |
| `setVueModel` | 跨 App 写 Vue 模型 |
| `setvar` | 写参数上下文变量 |
| `calc` | 安全表达式运算（+=/-=/*=//=） |
| `chain` | 动作链（多步组合） |
| `switch` | 条件分支 |
| `grid` | 刷新 DynTable 表格 |
| `copy` / `download` / `redirect` | 剪贴板/下载/跳转 |

### 5.3 入库动作（DynActionHelper）

在 `/Platform/Mgmt/DynActionHelperMgmt` 中可注册自定义动作（脚本型 / API 型 / 链型），前端启动时自动从 `/api/platform/dynactionhelper/all` 拉取注册。

## 6. 页面生成向导

**路由**：`/Platform/Page/PageGen`

1. **选择项目**：Business（业务库）或 __platform__（平台库）
2. **选择表**：自动列出该项目下所有表
3. **选择字段**：勾选列表展示字段、表单字段、查询字段
4. **生成**：自动创建 PageSetting（Filter/List/Detail 三屏配置）+ DynWebPage 实例
5. 生成的页面使用 `filterlist-crud` 或 `triscreen-blocks` 模板

## 7. 权限管理

### 7.1 权限模型

| 表 | 说明 |
|----|------|
| `SysUser` | 用户（默认 1 个管理员） |
| `SysRole` | 角色 |
| `SysUserRole` | 用户-角色关联 |
| `SysResource` | 资源（菜单/按钮/API） |
| `SysResourcePermission` | 资源-角色权限 |

### 7.2 权限拦截

- **全局过滤器** `PermissionFilter`：未登录 API 返回 401，页面跳转登录
- **API Key 中间件**：`X-Api-Key` 头可绕过登录（本地开发放行）
- **行级数据权限**：`IPermissionHook` 接口，业务项目可自定义（DemoRowLevelHook 为示例）

## 8. 字典与通用选项

**API**：`/api/dyncommon/dicts?type=xxx`

- `DynDict` 表存储平台字典（6 条种子）
- 下拉选项支持 4 种数据源：
  - `static`：静态 optionValues / optionValuesText
  - `dict`：平台字典（dictType）
  - `table`：工程表（支持 parentField 联动）
  - `ajax`：任意接口（支持 `{{model.field}}` 占位）

## 9. 组件开发指南

### 9.1 组件双定义源

1. **Razor View 优先**：`Views/Shared/Components/*.cshtml`，用三段标记：
   ```
   <!--TEMPLATE_START--> ... <!--TEMPLATE_END-->
   <!--SCRIPT_START--> ... <!--SCRIPT_END-->
   <!--STYLE_START--> ... <!--STYLE_END-->
   ```
2. **数据库回退**：`ComponentMeta` 表（64 条种子），存储 TemplateContent / ScriptContent / StyleContent

### 9.2 新增组件步骤

1. 在 `Views/Shared/Components/` 创建 `.cshtml`（三段标记）
2. 在 `ComponentMeta` 表插入元数据（可选，View 优先时自动扫描发现）
3. 组件通过 `dyn-dynamic-com` 标签在模板中使用
4. 配置契约键名全小写无分隔（comoptions / labeloptions / itemoptions）

### 9.3 配置契约（不可破）

```json
{
  "component": "DynElInput",
  "modelname": "Name",
  "options": {
    "comoptions": { "placeholder": "请输入名称", "size": "small" },
    "labeloptions": { "label": "名称", "required": true, "show": true },
    "itemoptions": { "style": {}, "class": "" },
    "compassthrough": "comoptions.size,labeloptions.labelposition"
  },
  "validators": [
    { "type": "required", "message": "名称必填" }
  ]
}
```

## 10. 常见问题

### Q: 页面打开空白，控制台报 mountCore 错误
A: 检查 `dyn-init="createApp"` 的元素内部是否有 `<script tag="dynconfig">`，且该 script 内定义了 `dynConfig` 对象。

### Q: V2 BlockApp 事件不触发
A: 确认两个 BlockApp 传了同一个 `ExecId`，且模板根元素调用了 `DynEventBus.registerRoot(rootEl)`。

### Q: 保存后树不刷新
A: DetailApp 的 `saved` 事件需要在模板 Scripts 段转换为 TreeApp 的 `reload` 事件（见 TreeDetailV2.cshtml）。

### Q: 设计器改了属性但运行时不生效
A: 确认保存后页面 JSON 已写入 PageSetting.ConfigJson；运行时自动剔除 designerMeta 是正常行为。

### Q: 连不上数据库
A: 默认使用 SQLite（`App_Data/Platform.db`），无需安装。如需切换 SQL Server，修改 `appsettings.json` 的 `ConnectionStrings` 和 `Db:Provider`。
