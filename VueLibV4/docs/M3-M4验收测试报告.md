## 1. 验收范围

### 1.1 M3 设计器属性闭环

1. 全组件 `PropertyConfigJson`（PropsMeta）配置化，右侧属性面板由 `DynDynamicCom` 渲染，`v-model` 经 `_.get/_.set` 回写画布 JSON
2. 属性面板即时闭环：标签（label）、占位符（placeholder）、必填（required）等属性"右侧面板编辑 → 画布实时变化 → JSON 同步"三方一致
3. 校验 Tab：required/email/phone/pattern/min/max/length/custom 共 8 类规则；`dyn-validator.js` 加入 DYN_MODULES（此前未加载导致校验静默失效）
4. 设计器弹窗化：`DynDesignerDialog` 以 layui layer iframe（type:2）打开设计器，父子页 `postMessage` 协议通信
5. 弹窗协议：`dyn-designer-ready` / `dyn-designer-init` / `dyn-designer-result` / `dyn-designer-cancel` 四类消息，保存回传 `{configJson, defaultModel}`

### 1.2 M4 三屏模板 + 页面生成

1. PageGen 向导：选项目 → 选表 → 字段/控件推断（输入框/数字/下拉字典/日期/多行文本）→ 一键生成 filter/list/detail 三套 PageSetting + DynWebPage 登记
2. 固定运行模板 `Run.cshtml`：筛选区 + 列表区分块挂载，共享 scope（`data-dyn-shared-scope`）联动
3. DynTable 数据表格：数据列 + 行操作列同构渲染、服务端分页、字典下拉筛选、字段排序、行操作（编辑弹窗）
4. Detail 片段：layer fragment 弹窗、行数据回填、保存（有主键 Update / 无主键 Insert）
5. 保存闭环：后端 `ApiResult` 下发 `showmessage(success) + grid 刷新 + close` 三连 dyn-actions

### 4.5 保存（Update / Insert / 失败，TC-M4-09/10/12）

```text
POST /Business/Templates/Save?code=student_web   （XHR，body 为 scope model）

编辑（Id 有值）→ {"code":0,"msg":"更新成功","dyn-actions":[
    {"action":"showmessage","options":{"message":"更新成功","type":"success"}},
    {"action":"grid","options":{"gridId":"grid_student_web"}},
    {"action":"close"}]}
  → DB 回读：Score=88、Address=...12号-改 ✅

新增（无 Id）  → {"code":0,"msg":"新增成功", ...三连动作...}

空模型        → {"code":500,"msg":"保存失败：Sequence contains no elements"}
  （GetBaseException 后的真实内层信息；前端 error toast，弹窗不关闭）
```

## 6. 验收中发现的缺陷与修复记录

两个里程碑累计发现 **15 项缺陷**，均已修复并回归通过：

| 编号 | 阶段 | 严重级 | 缺陷 | 根因 | 修复 |
|---|---|---|---|---|---|
| BUG-09 | M3 | 高 | 设计器脚本某处 const 变量被重新赋值，页面初始化中断 | ES Module 风格误用 | 改 let/变量重命名 |
| BUG-10 | M3 | 高 | 组件异步注册存在竞态，偶发"组件未定义" | ensureRegistered 与挂载时序无去重 | 注册 Promise 去重缓存 |
| BUG-11 | M3 | 高 | SQLite 新增后实体 Id 不回填 | ExecuteCommand 在 SQLite 不保证自增回填 | 统一改 ExecuteReturnIdentity（PageSetting 等多处） |
| BUG-12 | M3 | 中 | 旧库升级时 PageSetting 表缺失 | 表结构未幂等补建 | Seeder 增加旧库建表/补列 |
| BUG-13 | M3 | 中 | 设计器 Razor 视图跨 section 标签导致编译失败 | Razor 标签在 section 间未闭合 | 规整标签层级 |
| BUG-14 | M3 | 高 | 设计器弹窗保存无反应且无报错（DataCloneError） | TopBar postMessage 直接传 Vue3 Proxy，结构化克隆抛异常被 try/catch 静默吞 | postMessage 前 JSON 序列化（Proxy → 纯对象） |
| BUG-15 | M3 | 高 | mountConfig 中 `__pageCfg` 模板内读不到 | Vue3 实例代理不暴露下划线开头的 setup 键 | 改名 `pageCfg`（dyn-core.js mountConfig） |
| BUG-16 | M4 | 高 | DynTable 表格无列无数据且无报错 | `_BaseLayout` setup 仅暴露公共变量，rows/columns 等业务变量未挂 comExtra | setup 末尾 Object.assign(comExtra,{rows,total,columns,tableColumns,loadList,...}) |
| BUG-17 | M4 | 中 | 操作列以独立 v-for + 条件 vnode 渲染时整表中止 | 该版 ElementPlus（2.14.5）列收集对 v-for 后的条件 vnode 处理异常，vnode.el 为注释节点 | 操作列以 `{prop:'__ops__',isOps:true}` 并入数据列同一数组（tableColumns 方案） |
| BUG-18 | M4 | 高 | layer 弹窗报 `d.parents is not a function`；改用 jQuery 包装后弹层与内容均不进 DOM 且无报错 | layer type:1 内部对 content 调 jQuery 方法，原生 DOM 不支持；且游离（未 appendChild）元素走 wrap/show 分支失败 | holder 先 appendChild 到 body（display:none），content 传 layui.$(holder)；end 回调 remove |
| BUG-19 | M4 | 高 | 弹窗内容报 `Cannot read properties of null (reading 'textContent')` | fragment 挂载到外层 holder，Vue 挂载清空容器时内部 #detailCfgData 被一并清掉 | 改挂内部 `[data-dyn-init-createapp]` 块（切换 data-dyn-mode 后 dyn.mount），无内部块才回退外层 |
| BUG-20 | M4 | 高 | 编辑弹窗 Id/Age/Score 回填为 null，手填数值约 1s 内被弹回 null | EP 2.14.5 el-input-number 显式绑定 min:null/max:null 覆盖默认 ±Infinity，钳制逻辑误判越界并 emit(null)；生成器还显式写入 min:null/max:null | ① InputNumber 用 numBind computed 运行时剔除 null/空 min、max；② PageGen 不再生成 min/max:null（仅 step:1）；历史配置靠运行时剔除兼容，无需重新生成 |

## 9. 验收结论

**M3（设计器属性闭环）与 M4（三屏模板 + 页面生成）验收通过。**

- 构建结果 0 警告 0 错误；
- 20 项验收用例全部通过（M3 7 项、M4 13 项，无失败项、无仅走查项）；
- 累计 15 项缺陷全部修复并经浏览器回归确认，其中 4 项为高严重级的端到端阻断问题（业务变量未暴露、layer fragment 挂载链、数值回填被 EP 清空、新增按钮属性名不被委托识别）；
- 核心链路完整闭环：**选表生成 → 列表查询/字典筛选/服务端排序 → 编辑弹窗全字段回填 → Update 三连动作落库 → 新增 Insert 自增 Id → 取消/失败路径安全**，并经 API 回读数据库验证；
