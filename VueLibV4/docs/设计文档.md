# VueLibV4 设计文档

> 基于 V1（Razor View + DB 双定义组件）与 V3（Vue3 UMD 动态渲染器 + 可视化设计器）融合的低代码平台。

---

## 1. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端框架 | ASP.NET Core 8 (net8.0) | MVC + Areas 路由 |
| 数据库 | SQLite（默认）/ SQL Server（可切换） | 通过 `Db:Provider` 配置切换 |
| ORM | SqlSugar 5.1 | 支持 CodeFirst + DbMaintenance 元数据读取 |
| JSON | Newtonsoft.Json | 信封序列化 + JObject 动态 CRUD |
| 前端框架 | Vue 3.5 UMD（h() 函数式渲染） | 无构建工具，浏览器直接运行 |
| UI 库 | ElementPlus + Layui（均 UMD） | 双 UI 平台并存 |
| 样式 | Tailwind CSS（CDN 版） | 设计器 + 运行时共用 |
| 拖拽 | SortableJS + vue-draggable-plus | 设计器拖拽排序 |
| 图表 | ECharts | DynEChart 组件 |
| 代码编辑 | CodeMirror | DynCodeMirror 组件 |
| HTTP | Axios UMD | 前端网络层 |

## 3. 后端架构

### 3.1 启动流程

```
Program.cs
  ├─ builder.Services
  │   ├─ AddControllersWithViews + AddNewtonsoftJson（信封序列化）
  │   ├─ AddSingleton<DbFactory>()           // 数据库工厂
  │   ├─ AddScoped<DynamicCrudService>()     // 免模型 CRUD
  │   ├─ AddScoped<RazorComponentRenderer>() // Razor 渲染器
  │   └─ AddScoped<ComponentService>()       // 组件元数据服务
  ├─ Seeder.Run()  // 启动时初始化 SQLite（幂等：表不存在才执行）
  ├─ UseStaticFiles + UseRouting
  └─ MapGet("/") → Redirect("/Platform/Page/Desktop")
```

### 3.2 双库设计

| 数据库 | 连接串键 | 用途 | ORM 访问方式 |
|--------|---------|------|-------------|
| PlatformDb | `ConnectionStrings:PlatformDb` | 平台元数据（组件/模板/页面/动作/字典/桌面） | `DbFactory.PlatformDb()` → SqlSugarClient |
| BusinessDb | `ConnectionStrings:BusinessDb` | 示例业务数据（Student/Course/BusinessDict） | `DbFactory.BusinessDb()` |
| ProjectDb | 运行时传入 | 各 DynProject 持有的独立业务库 | `DbFactory.ProjectDb(connectionString)` |

`DbFactory` 自动识别 SQLite（`Data Source=...`）vs SQL Server（`Server=...`），相对路径自动解析为应用基目录下的绝对路径。

### 3.3 组件双定义源

组件有两层定义源，**DB 元数据优先**（与 V1 的"View 代码优先"设计有调整）：

| 源 | 位置 | 内容 | 用途 |
|----|------|------|------|
| ① ComponentMeta 表 | PlatformDb.ComponentMeta | ViewPath / LoadUrl / PropsMeta / AllowDrop 等元数据 | 设计器组件库、属性面板、拖拽准入 |
| ② Razor View 代码 | `Areas/Platform/ElementUI/{Name}.cshtml` 或 `Areas/Platform/Common/{Name}.cshtml` | `<!--TEMPLATE_START-->` / `<!--SCRIPT_START-->` / `<!--STYLE_START-->` 三段标记 | 后端渲染时提取为 ComponentDefineDto |
| ③ DB 内组件内容 | ComponentMeta.TemplateContent / ScriptContent / StyleContent | 同 Razor View 的三段内容 | Razor 渲染失败时的回退 |

**解析链路**：

```
前端请求 GET /api/component/define/{name}
  → ComponentService.GetDefineByName(name)
    → 查 ComponentMeta 表
    → 若 row.ViewPath 不为空 → RazorComponentRenderer.RenderByPath(viewPath, name)
      → IRazorViewEngine.GetView 渲染 .cshtml 为 HTML 字符串
      → 正则提取 TEMPLATE/SCRIPT/STYLE 三段标记
    → 若 Razor 失败或无 ViewPath → 回退 DB 内 TemplateContent/ScriptContent
  → 返回 {componentName, templateContent, scriptContent, styleContent}
```

**Razor 组件文件约定**：

```razor
@model VueLibV4.Web.Dtos.ComponentViewModel
@{ Layout = null; }
<!--COMPONENT_TYPE:0-->
<!--TEMPLATE_START-->
<div class="my-comp">{{ title }}</div>
<!--TEMPLATE_END-->
<!--SCRIPT_START-->
export default { name: "MyComp", props: { title: String } };
<!--SCRIPT_END-->
<!--STYLE_START-->
.my-comp { padding: 8px; }
<!--STYLE_END-->
```

同时兼容 V1 旧格式：`<template>...</template>` + `<script tag='comconfig'>var comConfig = {...}</script>`。

### 3.4 免模型动态 CRUD

`DynamicCrudService` 基于 SqlSugar 的 `DbMaintenance` 读取数据库元数据，无需定义实体类即可完成增删改查：

- **元数据**：`Tables()` / `Columns()` / `PrimaryKeys()` — 从 `INFORMATION_SCHEMA` 读取
- **分页查询**：`Page(db, table, page, size, filter)` — filter 支持 `{col: value}` 精确匹配和 `{col: {op, value}}` 条件操作符
- **增删改**：`Insert()` / `Update()` / `Delete()` — 按列 DataType 自动做类型转换

**过滤器语法**：

```json
{
  "Name": "张三",
  "Age": { "op": "gt", "value": "18" },
  "ClassName": { "op": "like", "value": "一" },
  "__orderby": "CreateTime desc"
}
```

支持的 op：`eq` / `neq` / `gt` / `ge` / `lt` / `le` / `like` / `notlike` / `in` / `between`

### 3.5 Seeder 初始化

启动时执行（幂等）：

1. 打开 PlatformDb SQLite 库（不存在则创建文件）
2. 检查 `ComponentMeta` 表是否存在
   - **不存在** → 依次执行 `platform.sql` + `component-meta.sql`
   - **存在但组件不全**（有旧名 ElFormItem 或缺 DynElContainer）→ 清空 ComponentMeta 后重跑 `component-meta.sql`
   - **存在且齐全** → 跳过

## 4. 前端架构

### 4.1 资源加载链路（dyn-lib.js）

```
dyn-lib.js（唯一入口）
  → 顺序加载第三方 UMD 库
    vue.global.prod.js
    lodash.min.js
    element-plus (css + js + icons)
    layui (css + js)
    tailwind.css
    sortable.min.js
    vue-draggable-plus.umd.js
    codemirror (css + js)
    axios.min.js
  → 顺序加载 dyn 模块（严格有序）
    dyn-load-com.js → dyn-render.js → dyn-com.js → dyn-core.js
    → dyn-designer-ops.js → dyn-designer-sortable.js
    → dyn-action.js → dyn-template.js
  → DynLib._fireReady()
    → dyn.initActions(document.body)  // 扫描 data-dyn-init-* 初始化动作
    → 执行所有 DynLib.ready(callback) 回调
```

`DYN_LIB_CONFIG` 可在页面中覆盖默认行为（如 `loadLayui: false` / `disableEvalJs: true`）。

### 4.2 运行时渲染模型

**核心**：`DynRender` 递归渲染器，接受 **cfg 配置树**（纯 JSON），用 Vue 3 `h()` 函数式 API 生成真实 VNode。

**cfg 配置树结构**：

```json
{
  "component": "DynForm",
  "options": {
    "comoptions": { "label": "姓名", "modelname": "name" },
    "labeloptions": { "show": true },
    "itemoptions": { "class": "p-4" },
    "comlisteners": { "change": "dyn-setVueModel" }
  },
  "childrenctrls": [
    {
      "component": "ComInput",
      "options": { "comoptions": { "modelname": "name" } }
    }
  ],
  "slots": { "default": [{ "component": "ComInput", ... }] }
}
```

**渲染流程**：

```
DynCore.normalize(cfg) → 补全 options 默认值
DynCore.mount(cfg, container)
  → Vue.createApp({ setup() { return h(DynRender, { cfg }); } })
  → DynRender 递归：对每个 cfg 节点
    → 若 __expr 属性 → new Function() 表达式求值
    → 从 cfg.component 查注册表 → 拿到 Vue 组件选项
    → h(组件, props, children)
    → 对 childrenctrls 递归调用
```

### 4.3 组件注册机制

```
dyn-lib.js ready → DynCom.setupApp(app)
  → DynCom.ensureRegistered(app)     // 注意：_regPromise bug 导致每次都 fetch
    → fetch('/api/component/list')    // 拉取所有 ComponentMeta
    → 遍历 metas → 对每个 LoadUrl 不为空的组件
      → vueLoadCom(name)             // 从 ComponentMeta.ViewPath 拉 Razor 渲染结果
        → fetch('/api/component/define/{name}')
        → new Function('return ' + scriptContent)()  // 解析 export default
        → 注入 template + style
        → ComponentRegistry.register(name, options)
    → 对 LoadUrl 为空的组件（全局组件）
      → 直接注册（如 ElFormItem）
```

### 4.4 动作系统（dyn-action.js）

**动作四类**：

| 类型 | 说明 | 示例 |
|------|------|------|
| script | JS 脚本，上下文 `$action/$args/$ctx/$api/$model` | `postback` / `setVueModel` / `evaljs` |
| url | 跳转 URL | `open('/dashboard')` |
| api | 调用后端 API | `/api/business/dyndata/page` |
| chain | 动作链，支持 `when` 条件 | 先 `confirm` 再 `postback` |

**内置 10 个动作**：`postback` / `postdata` / `confirm-postdata` / `reload` / `open` / `close` / `updateel` / `evaljs` / `load` / `setVueModel` / `showmessage` / `redirect`

**属性委托模型**：`data-dyn-{event}-{action}` 或 `data-dyn-init-{action}`

```html
<button data-dyn-click-postdata='{"url":"/api/save","data":{"name":"{{model.name}}"}}'>保存</button>
<div data-dyn-init-setVueModel='{"modelname":"name","value":"张三"}'></div>
```

**组合动作**：`$before` → 主动作 → `$onSuccess` / `$onFail` → `$after`

**事件总线**：`DynBus.on(name, handler)` / `.emit(name, payload)` — 组件间解耦通信

### 4.5 设计器架构

**设计器四分区 + scope 共享**：

```
data-dyn-shared-scope="designer"  // 根元素，创建唯一 reactive model
├── TopBar          data-dyn-init-createapp data-dyn-use-scope="designer"
├── LeftPanel       data-dyn-init-createapp data-dyn-use-scope="designer"
├── Canvas          data-dyn-init-createapp data-dyn-use-scope="designer"
└── RightPanel      data-dyn-init-createapp data-dyn-use-scope="designer"
```

每个分区独立 `createApp`，但通过 `WeakMap` 指向**同一份 reactive scope 对象**，实现跨分区共享状态（组件选中、画布 cfg、属性面板值等）。

**核心设计决策**：

- **画布不包装额外 div** — 选中框/拖拽手柄为绝对定位悬浮层，不干扰 flex/grid 布局
- **组件拖拽准入** — ComponentMeta.AllowDrop / CanDropInto / AcceptAll 属性控制
- **属性面板** — ComponentMeta.PropsMeta JSON 自动渲染（类型：input/select/color/number/boolean/slider）
- **模板导入导出** — dyn-template.js：ElementPlus Vue Template ↔ DynCom JSON
