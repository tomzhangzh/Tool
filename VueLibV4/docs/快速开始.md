# VueLibV4 快速开始

> 从零到跑通，预计 5 分钟。

---

## 1. 环境要求

| 依赖 | 版本 | 安装方式 |
|------|------|---------|
| .NET SDK | 8.0+ | [dot.net](https://dot.net) 下载安装包，或 `winget install Microsoft.DotNet.SDK.8` |
| Node.js | 可选（仅调试前端时需要） | 18+ |
| Git | 可选 | 任意版本 |

> **不需要安装 SQL Server**：默认使用 SQLite，`Data Source=App_Data/Platform.db` 会在首次启动时自动创建。

---

## 2. 克隆并运行

```bash
# 克隆（或直接打开目录）
cd VueLibV4

# 进入项目
cd src/VueLibV4.Web

# 还原依赖 + 运行
dotnet run
```

首次运行时 Seeder 会自动：
1. 在 `src/VueLibV4.Web/bin/Debug/net8.0/App_Data/` 下创建 `Platform.db`（SQLite 文件）
2. 执行 `Data/platform.sql` 建 9 张平台表 + 3 张业务表
3. 执行 `Data/component-meta.sql` 种入 ~70 个 ComponentMeta 组件元数据

看到日志 `[Init] 平台库初始化完成` 即初始化成功。

## 4. 切换到 SQL Server（可选）

编辑 `appsettings.json`：

```json
{
  "ConnectionStrings": {
    "PlatformDb": "Server=localhost;Database=VueLibV4Platform;Trusted_Connection=True;TrustServerCertificate=True;",
    "BusinessDb": "Server=localhost;Database=VueLibV4Business;Trusted_Connection=True;TrustServerCertificate=True;"
  },
  "Db": {
    "Provider": "SqlServer"
  }
}
```

> ⚠️ 切换 SQL Server 后，`Data/platform.sql` 和 `Data/component-meta.sql` 中的 SQLite 方言（如 `INTEGER PRIMARY KEY AUTOINCREMENT`）需要手动改写为 SQL Server 兼容语法（`INT IDENTITY(1,1)`）。建议先用 SQLite 跑通，再迁移到 SQL Server。

## 5. 一分钟上手：创建你的第一个动态页面

### 步骤 1：打开设计器

浏览器访问 http://localhost:5010/Platform/Page/Designer

### 步骤 2：从组件库拖组件

- 左侧"组件库"Tab → 找到"表单容器"分类 → 拖 `DynForm` 到画布
- 再拖 `ComInput` 到 DynForm 内部
- 再拖 `ComSelect` 到 DynForm 内部
- 拖 `ComHidden` 到 DynForm 内部

### 步骤 3：在属性面板绑定

- 点击画布上的 `ComInput` → 右侧属性面板 → **modelname** 填 `name`
- 点击 `ComSelect` → modelname 填 `gender` → **options** 填 `[{"label":"男","value":"M"},{"label":"女","value":"F"}]`
- 点击 `ComHidden` → modelname 填 `id`

### 步骤 4：导出模板

- 顶部栏 → "保存"按钮 → 输入模板名 `我的第一个表单` → 保存
- 或点击 "JSON" 按钮 → 查看生成的 cfg JSON

### 步骤 5：运行时渲染

创建一个 DynWebPage 记录：

```sql
INSERT INTO DynWebPage (Code, Name, PageJson, IsActive)
VALUES ('my-first-form', '我的第一个表单', '这里粘贴你导出的 cfg JSON', 1);
```

然后访问：

```
http://localhost:5010/Platform/Page/WebPageRender?code=my-first-form
```

就能看到设计器里设计的表单被动态渲染出来了。

## 6. 免模型 CRUD：学生表增删改查

### 方式 A：直接调用 API

```bash
# 分页查询
curl "http://localhost:5010/api/business/dyndata/page?table=Student&page=1&size=10"

# 按条件过滤（姓名含"张"且年龄>18）
curl "http://localhost:5010/api/business/dyndata/page?table=Student&filter={\"Name\":{\"op\":\"like\",\"value\":\"张\"},\"Age\":{\"op\":\"gt\",\"value\":\"18\"}}"

# 新增一条
curl -X POST http://localhost:5010/api/business/dyndata/insert \
  -H "Content-Type: application/json" \
  -d '{"table":"Student","data":{"Name":"王五","Age":22,"ClassName":"三班"}}'

# 更新
curl -X POST http://localhost:5010/api/business/dyndata/update \
  -H "Content-Type: application/json" \
  -d '{"table":"Student","data":{"Id":13,"Name":"王五（改）","Age":23}}'

# 删除
curl -X POST http://localhost:5010/api/business/dyndata/delete \
  -H "Content-Type: application/json" \
  -d '{"table":"Student","keys":{"Id":13}}'
```

### 方式 B：页面 Demo

访问 http://localhost:5010/Platform/Page/Demo/Crud → 选择 `Student` 表 → 即可看到完整的查询/重置/新增/编辑/删除界面。

## 7. 创建你的第一个 Razor 组件

### 步骤 1：创建 .cshtml 文件

在 `src/VueLibV4.Web/Areas/Platform/ElementUI/` 下新建文件 `MyButton.cshtml`：

```razor
@model VueLibV4.Web.Dtos.ComponentViewModel
@{ Layout = null; }

<!--COMPONENT_TYPE:0-->

<!--TEMPLATE_START-->
<el-button
  :type="comoptions.type"
  :size="comoptions.size || 'default'"
  :disabled="comoptions.disabled"
  @click="$emit('click')">
  {{ comoptions.text || '按钮' }}
</el-button>
<!--TEMPLATE_END-->

<!--SCRIPT_START-->
export default {
  name: "MyButton",
  props: {
    comoptions: Object,
    labeloptions: Object,
    itemoptions: Object,
    comlisteners: Object
  },
  emits: ['click'],
  setup(props, ctx) {
    return {};
  }
};
<!--SCRIPT_END-->
```

### 步骤 2：注册 ComponentMeta

在 SQLite 中执行（或通过 Dapper/SqlSugar）：

```sql
INSERT INTO ComponentMeta (ComponentName, Label, Category, UiPlatform, ViewPath, LoadUrl, PropsMeta, DefaultConfigJson, IsActive)
VALUES (
  'MyButton', '我的按钮', '基础控件', 'ElementUI',
  'Areas/Platform/ElementUI/MyButton.cshtml',
  '/api/component/define/MyButton',
  '[{"key":"text","label":"按钮文字","type":"input","group":"基础"},{"key":"type","label":"类型","type":"select","group":"基础"}]',
  '{"component":"MyButton","options":{"comoptions":{"text":"按钮","type":"primary"}}}',
  1
);
```

### 步骤 3：刷新设计器

打开设计器页面 → 组件库 Tab → 刷新 → 就能看到你新创建的 `MyButton` 组件。

### 步骤 4：验证 API

```bash
curl "http://localhost:5010/api/component/define/MyButton"
# 应返回从 Razor View 提取的 templateContent + scriptContent
```

## 8. 常见问题

### Q: 首次启动报错"平台库初始化失败"？

A: 检查 `src/VueLibV4.Web/bin/Debug/net8.0/App_Data/` 目录是否存在，若不存在手动创建一个。SQLite 依赖父目录存在。

### Q: 组件库为空？

A: 打开浏览器控制台 → `GET /api/component/list` 看是否返回数据。若返回空数组，说明 ComponentMeta 表没有记录，手动执行 `Data/component-meta.sql` 种子脚本。

### Q: 设计器拖拽无反应？

A: 控制台检查是否有 JS 错误。常见原因：ComponentMeta 的 `IsContainer` 字段为 false 但组件被当作容器拖入；或 AllowDrop/CanDropInto 配置冲突。

### Q: 切换 SQL Server 后 Seeder 报语法错误？

A: SQLite 和 SQL Server 语法不同。需要手动改写 `platform.sql`：
- `INTEGER PRIMARY KEY AUTOINCREMENT` → `INT IDENTITY(1,1) PRIMARY KEY`
- `TEXT` → `NVARCHAR(MAX)`
- `CURRENT_TIMESTAMP` → `GETDATE()`

### Q: 前端 console 报"dyn-com.js 加载组件清单失败"？

A: 检查 ComponentController 返回格式是 `{success, message, data}`，而前端 dyn-com.js 里判断的是 `res.data`，应兼容两种格式。

### Q: 如何关闭 evaljs 动作（安全加固）？

A: 在页面 `<head>` 里（dyn-lib.js 之前）加：

```html
<script>window.DYN_LIB_CONFIG = { disableEvalJs: true };</script>
```
