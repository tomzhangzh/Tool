## 应用简介

**华曜运动打卡** 是一款面向学校运动场景的打卡应用，支持 **老师 / 学生 / 家长** 三种角色。学生通过打卡运动记录健康数据，系统自动进行周评选与月度明星评选，激励孩子持续运动。

### 核心功能

| 功能 | 说明 |
|------|------|
| 🏃 运动打卡 | 选择运动项目、填写时长、自动计算卡路里 |
| ❤️ 点赞互动 | 同学之间可以互相点赞打卡记录 |
| 📊 数据统计 | 查看本周/本月运动统计数据 |
| 🏆 周评选 | 每周生成 6 类奖项（卡路里之星、时长之星等） |
| 🌟 月度明星 | 每月评选综合排名前 3 名 |
| 📱 班级动态 | 查看班级同学的打卡记录 |

## 角色说明

### 🧑‍🎓 学生
- 注册时需提供 **班级邀请码**（由老师创建班级后生成）
- 可以进行运动打卡、查看打卡记录
- 可以查看班级动态、同学排名
- 可以给同学的打卡记录点赞

### 👨‍🏫 老师
- 注册时需提供 **老师注册码**（统一口令：`hydxc`，不区分大小写）
- 可以创建班级、获取邀请码
- 可以查看班级所有学生的打卡记录
- 可以手动触发周评选和月度明星生成
- 可以查看班级排名

### 👨‍👩‍👧 家长
- 注册时需输入 **孩子的姓名**
- 可以查看孩子的运动数据、奖项、排名
- 可以给孩子的打卡记录点赞

## 快速开始

### 第一步：打开应用

用手机浏览器或电脑浏览器访问应用地址（由老师提供），建议添加到手机主屏幕以获得更好的使用体验。

### 第二步：注册账号

1. 打开应用，点击 **"注册账号"**
2. 选择角色：**学生 / 老师 / 家长**
3. 填写信息并提交

### 第三步：开始使用

- **学生**：自动加入班级 → 开始打卡
- **老师**：创建班级 → 获取邀请码 → 邀请学生
- **家长**：自动关联孩子 → 查看数据

## 学生使用指南

### 注册流程

1. 选择角色：**学生**
2. 填写以下信息：
   - **用户名**（唯一，用于登录）
   - **密码**（至少 6 位）
   - **确认密码**（再次输入密码）
   - **姓名**（真实姓名，会显示在打卡记录上）
   - **头像**（可选，点击生成随机头像）
   - **体重**（用于计算卡路里，默认 60kg）
   - **班级邀请码**（必填，从老师处获取）
3. 点击 **"注册"** 完成

### 登录

1. 输入用户名和密码
2. 点击密码框右侧的 **小眼睛图标** 可显示/隐藏密码
3. 点击 **"登录"**

### 打卡流程

1. 点击底部导航栏 **"打卡"**
2. 选择运动项目（跑步、快走、骑行、跳绳、篮球等）
3. 填写运动时长（分钟）
4. 可选填写备注和上传运动图片
5. 点击 **"完成打卡"**
6. 系统自动计算卡路里消耗

### 查看打卡记录

- 点击底部导航栏 **"打卡"**
- 可按 **全部 / 本周 / 本月** 筛选
- 点击记录上的 **❤️ 点赞数** 可查看谁点了赞
- 点击 **❤️ 爱心** 可给同学点赞

### 查看班级动态

- 点击底部导航栏 **"班级动态"**
- 可查看班级同学的打卡记录
- 可按 **今日 / 本周 / 本月** 筛选

### 查看排名

- 点击底部导航栏 **"排名"**
- 查看班级排名

### 修改个人信息

- 点击底部导航栏 **"我的"**
- 可修改头像、体重等信息

2. 填写以下信息：
   - **用户名**（唯一，用于登录）
   - **密码**（至少 6 位）
   - **确认密码**（再次输入密码）
   - **姓名**（真实姓名）
   - **头像**（可选）
   - **老师注册码**（必填：`hydxc`，不区分大小写）
3. 点击 **"注册"** 完成

### 创建班级

1. 点击底部导航栏 **"我的班级"**
2. 点击 **"➕ 创建班级"**
3. 输入班级名称
4. 点击 **"创建"**
5. 系统生成 **邀请码**（如 `A1B2C3`）
6. 将邀请码分享给学生

### 查看学生打卡

1. 点击底部导航栏 **"打卡"**
2. 可查看班级所有学生的打卡记录
3. 每条记录显示学生的头像和姓名
4. 自己的记录会标记 "(我)"
5. 可以给学生的打卡记录点赞

### 管理班级

1. 点击底部导航栏 **"我的班级"**
2. 可以查看班级成员列表
3. 可以复制邀请码

### 周评选

1. 点击底部导航栏 **"周榜"**
2. 查看已生成的奖项
3. 点击 **"🎲 一键生成本周评选"** 手动触发

### 月度明星

1. 点击 **"月度明星"** 标签
2. 查看已生成的月度明星
3. 点击 **"🎲 一键生成月度明星"** 手动触发

## 功能详解

### 运动项目

| 项目 | 图标 | MET值 | 每小时消耗(60kg) |
|------|------|-------|-----------------|
| 跑步 | 🏃 | 8 | 480 kcal |
| 快走 | 🚶 | 4 | 240 kcal |
| 骑行 | 🚴 | 6 | 360 kcal |
| 跳绳 | 🤸 | 10 | 600 kcal |
| 篮球 | 🏀 | 7 | 420 kcal |
| 足球 | ⚽ | 7 | 420 kcal |
| 羽毛球 | 🏸 | 5 | 300 kcal |
| 游泳 | 🏊 | 8 | 480 kcal |
| 跳舞 | 💃 | 5 | 300 kcal |
| 其他 | 💪 | 4 | 240 kcal |

**卡路里计算公式**：`卡路里 = MET × 体重(kg) × 时长(小时)`

### 周奖项说明

| 奖项 | 评选维度 | 说明 |
|------|---------|------|
| 🔥 卡路里燃烧之星 | totalCalorie | 本周累计消耗卡路里最多 |
| ⏱️ 运动时长之星 | totalDuration | 本周累计运动时长最长 |
| 📅 运动坚持之星 | checkinDays | 本周打卡天数最多 |
| 🎯 运动多面手 | exerciseTypes | 本周运动种类最丰富 |
| 📈 进步之星 | improvement | 本周比上周进步最大 |
| 🌅 早起运动之星 | earlyCheckin | 本周最早开始运动 |

每个奖项取前 3 名。

### 月度明星说明

**综合得分** = 卡路里 30% + 时长 30% + 频率 25% + 多样性 15%

| 奖项 | 说明 |
|------|------|
| 🏆 月度运动冠军 | 综合得分第 1 |
| 🥈 月度亚军 | 综合得分第 2 |
| 🥉 月度季军 | 综合得分第 3 |
| 💪 月度坚持之星 | 打卡满 20 天 |
| 🌟 月度进步之星 | 本月比上月进步最大 |

### 时间格式

打卡记录时间显示规则：
- **今天** → `今天 14:30`
- **昨天** → `昨天 14:30`
- **今年内** → `08-09 14:30`
- **其他年份** → `2024-08-09 14:30`

## 常见问题

### Q1: 忘记密码怎么办？
目前暂不支持找回密码，请联系老师或管理员重置。

### Q2: 邀请码无效怎么办？
请确认：
1. 邀请码是否正确（注意大小写）
2. 班级是否已创建
3. 班级是否处于活跃状态

### Q3: 如何修改体重？
进入 **"我的"** → 点击头像下方的体重信息 → 修改后保存。

### Q4: 老师注册码是什么？
老师注册码为 `hydxc`（不区分大小写）。

### Q5: 打卡图片看不了？
图片使用云存储临时链接，有效期 2 小时。如果无法查看，请刷新页面重新加载。

### Q6: 如何添加到手机主屏幕？
- **Android Chrome**：菜单 → "添加到主屏幕" 或 "安装应用"
- **iOS Safari**：分享 → "添加到主屏幕"

### Q7: 如何退出登录？
进入 **"我的"** → 底部点击 **"退出登录"**。

### Q8: 班级动态不显示怎么办？
请确认：
1. 学生是否已注册并加入班级
2. 是否有打卡记录
3. 尝试刷新页面

### Q9: 点赞功能如何使用？
- 点击 **❤️ 爱心** 图标点赞/取消点赞
- 点击 **❤️ 点赞数** 查看谁点了赞

### Q10: 如何联系管理员？
如有问题，请联系学校体育老师或系统管理员。
